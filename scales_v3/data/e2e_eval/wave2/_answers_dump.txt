STU_GOOD:
TCP opens a connection using a three-way handshake.
First the client sends a SYN segment with its initial sequence number so the server knows the client wants to connect and which seq to expect.
The server replies with SYN-ACK: it sets its own initial sequence number and acknowledges the client's SYN with ack = client_ISN + 1.
Finally the client sends an ACK with ack = server_ISN + 1 to confirm the server's SYN.
This synchronizes both sides and sets up a reliable connection before data is sent.

STU_GOOD_ALT:
Connection setup uses three steps.
1) Client → server: SYN with starting sequence number (ISN) to request a connection.
2) Server → client: SYN-ACK carrying the server ISN and acknowledging the client with ack = client ISN + 1.
3) Client → server: ACK with ack = server ISN + 1 confirming the server SYN.
Goal: synchronize sequence numbers and establish a reliable full-duplex session before sending data.
